# AutoValue

AutoValue is a machine learning web application that estimates the resale price of used cars in the Indian market based on vehicle characteristics.

## Objective

The objective of this project is to build a machine learning model that can estimate the resale value of a used car using information such as its brand, model, variant, body type, transmission, fuel type, year, kilometers driven, number of owners, and accident history.

## Dataset

The project uses the Indian Car Dataset from Kaggle.

Dataset: https://www.kaggle.com/datasets/milapgohil/car-dataset

The dataset contains 140,000+ vehicle records covering multiple brands, models, variants, vehicle types, fuel types, transmission types, ownership information, accident history, and prices.

## Features Used

The model uses the following features:

* Brand
* Model Name
* Model Variant
* Car Type
* Transmission
* Fuel Type
* Year
* Kilometers Driven
* Number of Owners
* Accident History

Categorical features are encoded using OneHotEncoder, while numerical features are passed through the preprocessing pipeline.

## Machine Learning Model

AutoValue uses a Gradient Boosting regression model to predict the resale price of a vehicle.

The project uses a scikit-learn pipeline to combine preprocessing and model prediction into a single workflow.

## Application

The application consists of:

* HTML/CSS/JavaScript frontend
* FastAPI backend
* Scikit-learn machine learning pipeline
* Dynamic brand, model, and variant selection
* Real-time prediction through the deployed API
